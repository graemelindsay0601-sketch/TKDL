---
name: Career visual and navigation standard
description: Product-wide visual and navigation expectations for TKDL Career screens.
---

Career mode should maintain a premium, visually distinctive presentation across all pages rather than relying on plain text blocks. Use TKDL's navy, red, and gold identity rather than a green-led palette. Screens should make key information scannable, keep labels and metrics inside their visual containers, and provide clear ways to move between related Career pages and return to the main Career areas. Weekly schedule entries should open the relevant event or activity. Career reviews and mockups must use the current premium shirt artwork, not legacy flat-vector shirts.

**Why:** The user asked for a full visual and navigation overhaul because several Career pages, including Overview, My Career, and Club, felt plain and difficult to navigate, explicitly rejected a green-led palette, and corrected a review frame that still showed old standard shirts instead of the premium kits.

**How to apply:** When adding or revising Career UI, check mobile and desktop layouts, navigation and return paths, and direct links from booked weekly items. Use the premium kit artwork on all Career mockups. Keep all additions compatible with existing Career saves.
