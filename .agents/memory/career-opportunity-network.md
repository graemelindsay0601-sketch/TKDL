---
name: Career opportunity network
description: Product direction for linking real Career progress to optional off-board opportunities.
---

Extend Career Life's existing off-board opportunity board rather than creating a second inbox. Opportunities should connect actual progression across Career systems, starting with a local-to-regional path earned through genuine club participation.

**Why:** The user approved building a Career Opportunity Network and selected a local-to-regional first path; they want Career choices to create meaningful opportunities beyond simply adding more darts matches.

**How to apply:** Keep eligibility based on persisted player-played results, preserve calendar conflicts and optional accept/decline choices, and distinguish these off-board commitments from tournament entries, stats, rankings, and simulated teammate cover.
