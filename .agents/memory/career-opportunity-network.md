---
name: Career opportunity network
description: Product direction for linking real Career progress to optional off-board opportunities.
---

Extend Career Life's existing opportunity board rather than creating a second inbox. The local spotlight remains an off-board appearance earned through genuine club participation. The regional invitation is direct entry to the next registration-open Regional Open and must use the standard event draw, scorer, fees, prizes, and ranking rules.

**Why:** The user chose entry to the next Regional Open over a separate showcase tournament so the invitation uses the existing official tournament pipeline.

**How to apply:** Keep invitation eligibility based on persisted player-played club results and completed local progression. Accepting records an event entry, not a completed result or appearance fee; only played tournament results affect sporting records and rankings. Preserve existing saves and optional accept/decline choices.
