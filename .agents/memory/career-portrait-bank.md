Replacement NPCs should draw from an appropriately tagged reserve pool without duplicating portraits within the same save.

Before generating or integrating anything, audit global player counts and nationalities, then estimate compressed asset storage and Render bandwidth. Keep image binaries out of Neon; store only a portrait reference in game data. The user wants to avoid new spend and remain on existing free tiers if possible, so do not promise zero cost without checking current provider usage and limits. Do not implement until the user reopens the idea.

**Why:** the user sees realistic portraits as a possible premium finish, but wants to weigh effort and ongoing Neon/Render usage before committing.

**How to apply:** if the user returns to this, begin with a read-only roster and asset-usage estimate. A private style sample may be reviewed first, but do not launch a partial portrait rollout.
