# Workstream E2 — premium trophy integration guide

Owner: integration owner. E2 deliberately did **not** edit `features/career/identity.tsx`, shared Career CSS, the router/shell or any server module.

## What E2 provides

`artifacts/tkdl/src/features/career/trophies/` (import from `../trophies` or `@/features/career/trophies`):

| Export | Purpose |
|---|---|
| `PremiumTrophy({ trophy, size, engraving?, eventName?, decorative? })` | Renders premium art for a catalogue identity. `trophy` accepts existing content shapes: `{ id, name, designKey }` (trophy rows), `{ trophyId }` (event content) or `{ designId }` (`trophyIdentity`). Sizes `xs · sm · md · lg · hero`. Unknown identities render an explicit labelled fallback with `data-missing-trophy`. |
| `AwardPresentation({ event, size?, eventName?, persistedTrophyId? })` | What a winner is shown receiving under the locked policy: premium trophy, plaque/medal, or a result-only marker. `persistedTrophyId` (stored `snapshot.content.trophyId`) keeps a historical event's identity. |
| `RecognitionMark({ form, size, label })` | Plaque, medal or result-only marker on its own. |
| `resolveAward({ definitionKey, circuit?, classification?, tier? })` / `awardsPhysicalTrophy(...)` | Policy lookup (versioned, explicit for all 95 definitions). |
| `groupTrophyWins(wins)` | Groups cabinet rows by `trophyIdentityId`, preserving exact counts. |
| `TrophyContactSheet({ ids, size })` | Review sheet of identities. |
| `TROPHY_ART`, `RECOGNITION_ART`, `trophyArt(id)` | Manifest (18 identities + 2 recognitions). |

Assets: `artifacts/tkdl/public/assets/career-trophies/*.svg` (20 files), generated by `node scripts/build-career-trophies.mjs` (deterministic). Audit report: `docs/career/e2-trophy-award-report.md`, regenerated by `node scripts/career-award-report.ts`.

## Integration steps

1. **Replace the shared renderer** in `features/career/identity.tsx`:
   ```tsx
   import { PremiumTrophy, TROPHY_ART, type TrophySize } from "./trophies";
   export function CareerTrophy({ name, design = "", id, size = "md", engraving }: { name: string; design?: string; id?: string; size?: TrophySize; engraving?: string }) {
     const known = Object.values(TROPHY_ART).find(a => a.id === id || a.designKey === design || a.name === name);
     return <PremiumTrophy trophy={{ id: known?.id ?? id ?? null, name }} size={size} engraving={engraving} />;
   }
   ```
   Existing callers pass `name` + `design` (the catalogue `designKey`), which resolve to the same identity. Remove the old inline SVG paths. The aria label still contains "not a crown" for the Sovereign.
2. **Trophy cabinet** (`world.tsx` `TrophyPage`, `legacy/components.tsx` `Shelf`/`HonoursShelf`): for each cabinet row call `resolveAward({ definitionKey: row.canonicalEventId, circuit: row.circuit, classification: row.classification })`. Render `AwardPresentation` with `persistedTrophyId={row.trophy?.id}`; group with `groupTrophyWins`. Rows that resolve to `RESULT_ONLY` stay listed as wins (counts unchanged), just without a trophy.
3. **Tournament hero, arrival & completion** (`tournament/components.tsx`): replace `CareerTrophy` with `AwardPresentation event={{ definitionKey: v.event.definitionKey, circuit: v.event.circuit, classification: v.event.classification }} persistedTrophyId={v.event.content?.trophyId} size="lg"`. Use `size="hero"` and wrap in `className="ct-reveal"` for the champion reveal (respects reduced motion).
4. **NPC honours, season reviews, Darts World honours, A Career Remembered**: use `AwardPresentation` with `size="sm"` beside each recorded title. Never derive a trophy from a name.
5. **CSS**: `trophies.css` is imported by the component module; no global CSS change is needed.

## Compatibility

- Presentation only: no server, sporting, finance, ranking or qualification module imports the policy (tested).
- Every physical award uses the event's existing catalogue `trophyId`, so no event changes identity. A stored `trophyId` alone never creates a physical trophy.
- Historic results, titles and repeat-win counts are unchanged. Qualifier and Q-School wins remain recorded achievements without trophies.
